5. **Sync cap and completeness.** New mailbox checkpoint fields persist a fixed inbox query window, pending IDs and next-page token, hidden from JSON. No watermark advances until the fixed window finishes. Incremental windows then start two minutes before the last completed boundary, catching arrivals during import. Caps also resume incremental pages. Exact-cap/no-next-page finishes; over-cap persists pending IDs/token. Repeated tokens/bounded empty pagination fail with the checkpoint retained. Tests cover under/exact/over cap, provider-page continuation, later incremental imports, repeated-sync identity, failure retry and pagination loops. Benchmark real pilot latency; SQLite/HTTP fakes do not certify provider rate/capacity.
